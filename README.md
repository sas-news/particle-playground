# Particle Playground

パーティクルライフ（吸引行列モデル）の生態系で遊ぶ、3つの小さなゲーム／実験のセットです。

公開サイト: **https://sas-news.github.io/particle-playground/**

| モード | 内容 | プレイヤーの関わり方 |
|---|---|---|
| **Particle Derby** | 生まれた群れの「生き残り」を予想して賭けるレース。3レース・チップ制 | 賭けるだけ（群れは操作しない） |
| **Particle Scoop** | 生態系の群れを90秒ですくい集める捕獲ゲーム | マグネットで環境を少し動かす |
| **Particle Lab** | 吸引行列と数値をランダム化して、生態系を眺める実験室 | 環境を揺らすだけ |

> 元ネタ: [パーティクルライフ](https://cerevisiae-fii.github.io/particle-life/)（非公式の二次創作的な実験作です）

---

## 設計方針

前バージョンでは「ヒモをすくう」捕獲ゲームを作りましたが、方針を立て直しました。

**この生態系の主役は、プレイヤーではなく粒子の群れそのもの**です。
プレイヤーが1体の生き物を完全に操作できるゲーム（スリザリオ型）は、
「勝手に生まれてくる群れを眺める」という本質を壊してしまうため**採用しませんでした**。

代わりに、すべてのモードでプレイヤーは **生態系の外側** にいます。

- 群れを動かす・指示する操作はない
- できるのは「観察」「予想」「環境への軽い干渉」だけ

## Particle Derby — 生き残り予想レース

### ゲームの流れ（1レース）

1. **培養（7秒）** — ランダムな吸引行列から、粒の群れが自然に生まれる
2. **出馬表（15秒・盤面停止）** — 大きめの群れを5つ選び、番号と名前をつけて提示。
   盤面を止めたまま、粒数・オッズ・危険度・調子・進行方向の矢印を見てチップを賭ける
   （チップ額を選ぶ → カードをタップ → 「レース開始で確定」）
3. **レース（26秒）** — 予告された 💥 の場所で大爆発。生態系が変わり、群れが合流・崩壊する
4. **結果** — レース終了時に「いちばん大きい群れ」が勝ち。賭けが当たれば配当

3レース終了時のチップ総額で S/A/B/C/D のランク。

### 何が難しいか／どう解いたか

**課題1: 一塊の「生命」を判別するのが難しい**

群れは明示的なオブジェクトではなく、粒子の集まりが毎フレーム形を変えます。
分裂・合流・崩壊が起きるため、単純な「重心の近さ」では同一性を追えません。

→ 解決: **粒子IDの重なり（血統追跡）**。
各候補の粒子集合を持ち、次のフレームのクラスタと重なり率（Jaccard 相当）が
22%以上のものを同じ血統とみなします。合流したら大きい血統が勝ち、
小さい血統は「合流」として脱落。これを 12.5Hz で更新し、
浮遊する番号バッジとハローで可視化しています。

**課題2: 動いている盤面では何も読めない**

出馬表のあいだは **シミュレーションを停止** します。止めた状態で、
群れの重心と平均速度から **進行方向の矢印** を描き、💥の予告位置と見比べられるようにしました。
「この群れは次の爆発までに輪の外へ出るか、中に残るか」を読むのが基本の判断になります。

**課題3: 予想ゲームに「読む余地」が必要**

ただ賭けるだけだと、結果がランダムで退屈になります。
そこで **予告付きの危険地帯（💥）** を導入しました。

- レース前に「あと何秒後に、どこが爆発するか」が表示される
- 爆発範囲に入っている群れは危険なので、オッズが高くなる
- プレイヤーは「大きいけど危険」か「小さいけど安全」かを読んで賭ける
- 予告は外れることがある（群れは動くし、分裂もする）ので、完全な最適解にはならない

そのほか、突然変異（行列の変化）、合流、崩壊がレースを撹乱します。

### スコアとオッズ

- オッズ = 粒数^1.05 × 調子 × 危険度ペナルティ から算出（ハウスエッジ込み）
- 賭けかた: チップ額（10/25/50）を選ぶ → 群れのカードをタップ → 「レース開始で確定」
  - カード内の `−10` で賭けを一部取り消し、「取り消す」で全額戻る
  - 当たれば `賭け × オッズ` が戻る。全滅レースは賭けを返金

> バランスはシミュレーションで調整中です。オッズの精度・イベント頻度は `src/derby.js` の
> `RACE_TIME` / `CULTIVATE_TIME` / `buildHazards()` / `computeOdds()` で調整できます。

## Particle Scoop — 捕獲ゲーム

- 90秒で、生態系の群れをリングに収めて捕獲
- 長い群れ・色数の多い群れ・注文に合う群れほど高得点
- 捕獲するとエネルギー回復、6秒以内の連続捕獲でコンボ
- トゲ胞子に触れるとエネルギーを失う
- 7世代（約13秒ごと）で培養液が入れ替わり、群れの構成が変化

プレイヤーはマグネットで粒子を引き寄せるだけで、群れそのものを操作はしません。

## Particle Lab — 観察・実験室

- 🎲 **引力・斥力をランダム化（原作準拠）**: 行列の全マスを -1〜1 の乱数で置き換えるだけ。
  粒の数・速度・半径などのパラメータは変えない（元サイトの🎲と同じ挙動）
- **行列の表を常時表示**: K×K のマスに数値と色（＋引力 / −斥力）を表示。ランダム化で全マスが変わるのを確認できる
- K（色の種類）/ N（粒数）/ 半径 / 力 / 速さ / 斥力 のスライダー
- 長押しでマグネット、ダブルクリック / Space でバースト
- 摂動モード: 行列がゆっくり変わり続け、生態系が止まらない
- いちばん大きい塊を自動ハイライト
- 「小さな群れが大量発生」「巨大な塊が暴走中！」などの状態表示
- プリセットの「ランダム変異」はひも状ベースの揺らぎ（原作の🎲とは別物）

元サイトの「ランダム化して、ちっちゃい生き物がうようよするのを眺める」体験を、
そのまま持ち込んだモードです。

```
worm-lab/
├── derby.html / src/derby.js   # Particle Derby
├── index.html / src/game.js    # Particle Scoop（旧: ヒモスイ）

├── src/sim.js                  # 物理コア・プリセット・kNNクラスタ解析

├── site/                       # GitHub Pages 公開用（ビルド済み）
```

```bash
node build.js

```

## 技術メモ

- 物理: 元実装の吸引行列モデル（`rmax` / `beta` / `F` / `dt` / `friction`）
- クラスタ検出: 近傍2個を繋いだ kNN グラフ + Union-Find + 主成分分析（細長さ）
- 血統追跡: 粒子ID集合の重なり率でフレーム間マッチング
- 描画: 加算合成のグロー + コアの2パス、0.62解像度の残像レイヤー
- 効果音: WebAudio で生成（外部アセットなし）
